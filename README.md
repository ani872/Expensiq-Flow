# 💰 Expensiq-Flow

> **Track Smart. Spend Better.**

A modern premium Expense Tracker Dashboard built using **HTML5, Tailwind CSS (CDN), Vanilla JavaScript, LocalStorage, Font Awesome, and Chart.js** — no npm, no build tools required.

---

## 🚀 Live Project Overview

Expensiq-Flow is a frontend-based expense tracking dashboard that provides:

- Real-time financial tracking
- Interactive analytics with Chart.js
- Responsive dashboard UI
- Dark mode support
- LocalStorage-based persistence
- Authentication system (Signup / Login)
- Dynamic charts and transaction management

The project is designed as a portfolio-quality frontend application inspired by real SaaS fintech products.

### 🔐 Authentication System

## ⚙️ Setup — Zero Installation Required

### 1. Clone the repository

```bash
git clone https://github.com/ani872/Expensiq-Flow.git
```

### 2. Open the project folder

```bash
cd Expensiq-Flow
```

### 3. Open in browser

Just double-click `index.html` — or use the Live Server extension in VS Code.

```
No npm install needed.
No build step needed.
No node_modules folder.
```

---

## 🔗 CDN Libraries Used

These are loaded directly in `index.html`:

```html
<!-- Tailwind CSS -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- Chart.js -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.4.1/chart.umd.min.js"></script>

<!-- Font Awesome -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css" />
```
